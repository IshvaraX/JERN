What JERN is

JERN (Just An Experimental Response Network) is a small personal assistant by Vivek Thakur. A fine-tuned 1.5B language model does the thinking; the tools do the work on this computer.

  • Local hands. Web search, page reading, downloads, browser, YouTube, maps, weather and mail run on your machine. Anything that changes something asks for your approval first.
  • Cloud brain, optionally. The model can run on a free Google Colab GPU. When it does, your messages and tool results are sent there.
  • Experimental. A small model sometimes picks the wrong tool or repeats itself. Read a command before you approve it.
